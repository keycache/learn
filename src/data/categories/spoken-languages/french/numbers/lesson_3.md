# Building Numbers 21-99: Patterns and Quirks

## The French Number System's Quirky Charm 🧩

Now that you've mastered 0-20, it's time to understand how French builds larger numbers. Here's the interesting part: French's approach to numbers 70, 80, and 90 is refreshingly different from English!

> **The Quirk**: While English uses words like "seventy," French actually counts: 60+10 (70), 4×20 (80), and 4×20+10 (90). This ancient system comes from Celtic languages and makes French numbers wonderfully logical!

## The Core Pattern: 20s Through 60s

### Numbers 21-29

After 20, we introduce a new number word: "et" (and). Here's how it works:

```
20 = vingt
21 = vingt et un (20 and 1)
22 = vingt-deux (20-2)
23 = vingt-trois (20-3)
...
29 = vingt-neuf (20-9)
```

**Key Point**: Notice that "vingt et un" (21) uses the conjunction "et" (and), but 22-29 do NOT use "et"—they use hyphens instead.

| Number | French | Pronunciation |
|--------|--------|----------------|
| 21 | vingt et un | van ay uhn |
| 22 | vingt-deux | van-duh |
| 25 | vingt-cinq | van-sank |
| 29 | vingt-neuf | van-nuhf |

### Numbers 30-69

From 30 onwards, the pattern becomes very regular. Each multiple of 10 is its own word:

- **30 = trente** (tront)
- **40 = quarante** (ka-ront)
- **50 = cinquante** (san-kont)
- **60 = soixante** (swah-sont)

And you build other numbers by adding:

```
31 = trente et un (30 and 1)
32 = trente-deux (30-2)
35 = trente-cinq (30-5)

45 = quarante-cinq (40-5)
56 = cinquante-six (50-6)
68 = soixante-huit (60-8)
```

**Rule Summary for 30-69**:
- Use the base number (trente, quarante, etc.)
- Add "et" (and) only for X1 (31, 41, 51, 61)
- Add hyphen and the second number for X2-X9

## The Quirky Numbers: 70, 80, and 90

### 70: Soixante-dix (60 + 10)

Instead of inventing a new word, French says "60 + 10":

```
70 = soixante-dix (literally: 60-10) - swah-sont-dees
71 = soixante et onze (60 and 11) - swah-sont ay onz
72 = soixante-douze (60-12) - swah-sont-dooz
73 = soixante-treize (60-13) - swah-sont-trez
...
79 = soixante-dix-neuf (60-10-9) - swah-sont-dees-nuhf
```

**Why "et" for 71?** Because the pattern treats "soixante-dix" as a compound, so "et" is added before the next unit.

### 80: Quatre-vingts (4 × 20)

This is perhaps the most famous French number quirk. Instead of "8 tens," it's "4 twenties":

```
80 = quatre-vingts (4 twenties) - ka-tr van
81 = quatre-vingt-un (4 twenties-1) - ka-tr van uhn
82 = quatre-vingt-deux (4 twenties-2) - ka-tr van duh
...
89 = quatre-vingt-neuf (4 twenties-9) - ka-tr van nuhf
```

**Spelling Alert**: Notice that "vingts" has an "s" when it's the final number (80), but loses the "s" when followed by another number (81, 82, etc.).

### 90: Quatre-vingt-dix (4 × 20 + 10)

Following the same pattern as 80:

```
90 = quatre-vingt-dix (4 twenties-10) - ka-tr van dees
91 = quatre-vingt-onze (4 twenties-11) - ka-tr van onz
92 = quatre-vingt-douze (4 twenties-12) - ka-tr van dooz
...
99 = quatre-vingt-dix-neuf (4 twenties-10-9) - ka-tr van dees nuhf
```

## Real-World Applications

### Prices and Costs
```
"C'est quarante-deux euros" (It's 42 euros)
"Ça coûte soixante-dix-neuf euros" (It costs 79 euros)
"C'est quatre-vingt-cinq francs" (It's 85 francs)
```

### Ages and Dates
```
"Mon grand-mère a quatre-vingt-trois ans" (My grandmother is 83 years old)
"Nous sommes le vingt-quatre décembre" (It's December 24th)
"L'année quatre-vingt-neuf" (The year 1989)
```

### Time
```
"Il est trois heures vingt" (It's 3:20)
"À quatre-vingt-dix heures?" (At 90 hours? - This would be unusual!)
```

### Phone Numbers and Addresses
```
"Le numéro est: quarante-deux, soixante-trois, quatre-vingt-dix-huit"
(The number is: 42, 63, 98)
```

## Common Mistakes to Avoid ❌

1. **Don't forget "et"**: Use "vingt et un" (21), not "vingt un"
2. **Don't add "et" after 20**: Use "vingt-deux" (22), not "vingt et deux"
3. **Remember the "s" in 80**: When 80 stands alone, it's "quatre-vingts" with an "s"
4. **Don't drop the "s" too early**: Write "quatre-vingt-un" (81) without the "s"
5. **Count carefully for 70-90**: Remember that 70 = 60+10, 80 = 4×20, 90 = 4×20+10

## Bonus: Why Does French Count This Way? 🤔

The French number system has ancient roots! The "4 × 20" system for 80 and 90 actually comes from Celtic languages and reflects historical trade patterns. Today, it's a distinctive feature of French (and Belgian Dutch speakers also use it!).

Interestingly, Swiss French and Quebec French sometimes have variations:
- Swiss French: "septante" (70), "nonante" (90)
- Quebec French: Matches standard French but with Quebec pronunciation

So if you travel to different French-speaking regions, you might hear different terms!
